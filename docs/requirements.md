# 要件定義書 — メルカリ出品文メーカー

## 1. 概要
古着をメルカリに出品する際、写真を撮って数項目を入力するだけで、AI（Claude）が出品文（タイトル・特徴・コーディネート例など）を自動生成し、完成した出品文をGoogleスプレッドシートに記録できるWebアプリ。

## 2. 対象ユーザー
古着をメルカリなどのフリマアプリで販売している個人・小規模な古着販売者。
（本アプリは「#古着屋Arua」という屋号を想定した文面テンプレートを使用）

## 3. 目的・解決したい課題
- 出品文を毎回ゼロから書くのが手間
- サイズ measurements や状態（コンディション）の表記を統一したい
- 出品した商品の情報（管理番号・価格・ジャンルなど）を一覧管理したい

## 4. 主な機能
1. **商品写真アップロード**
   - 最大5枚まで（`MAX_PHOTOS = 5`）
   - アップロード後、自動で画像を縮小してから送信
2. **手入力フォーム（manual入力）**
   - 商品の状態（6段階：新品〜全体的に状態が悪い）
   - ブランド名（任意）
   - 購入価格（任意、メモ用）
   - カテゴリ（トップス／ボトムス／ワンピース／アウター／バッグ／シューズ／その他）
   - サイズ実寸（カテゴリに応じて入力項目が変わる：肩幅・身幅・袖丈・着丈・ウエスト・股下など）
3. **AIによる出品文生成**
   - 写真＋手入力内容をAI（Claude、Vercel AI Gateway経由）に送信
   - 生成される内容：タイトル、素材、特徴文、コーディネート提案（2パターン）、系統タグ、デザイン特徴、色、価格帯（下限〜上限）、検索キーワード
4. **出品文の編集・確認画面**
   - AI生成結果と手入力情報を組み合わせて、挨拶文・注意書き・発送について・質問受付などの定型文とまとめた完成版の出品文を表示
   - ユーザーが文章を編集可能
5. **管理番号の自動取得**
   - Googleスプレッドシートの既存データから次の管理番号を自動算出
6. **Googleスプレッドシートへの保存**
   - 確定した出品情報（管理番号・商品名・ジャンル・系統・ブランド・出品価格・商品の状態）を1行として追記

## 5. 画面構成・操作フロー
1. トップページ（`/`）で写真アップロード＋手入力フォームを入力
2. 「出品文を生成する」ボタンを押す → `/api/generate` にPOST → AIが出品文を生成
3. 生成結果が編集画面（`ListingResultEditor`）に表示される
4. 内容を確認・編集し、保存ボタンで `/api/sheets/append` にPOST → スプレッドシートに1行追記

## 6. 使用技術（技術スタック）
- **フレームワーク**: Next.js（App Router）／Turbopack
- **言語**: TypeScript
- **AI**: Claude（`anthropic/claude-sonnet-5`）を Vercel AI Gateway 経由で呼び出し、`ai` パッケージの `generateText` + `Output.object` で構造化出力を取得
- **バリデーション**: zod（APIの入出力チェック）
- **データ保存先**: Google スプレッドシート（`googleapis` 経由でAPI連携）
- **ホスティング**: Vercel（本番公開）
- **Next.js設定**: Cache Components / Partial Prerendering（PPR）を有効化

## 7. 入出力データ（概要）
- **入力**: 商品写真（複数）、状態・ブランド・カテゴリ・サイズなどの手入力項目
- **AI出力**: タイトル、素材、特徴文、コーデ提案、系統タグ、デザイン特徴、色、価格帯、検索キーワード
- **保存データ（スプレッドシート列）**: 管理番号／商品名／ジャンル／系統／ブランド／出品価格／商品の状態

## 8. 非機能要件
- 環境変数（Google認証情報・シートID・AI Gateway鍵）はVercel側に設定済みで、コードには含めない
- 本アプリに出品履歴の閲覧機能は含まない（スプレッドシート側で管理）
- テスト自動化の仕組みは未導入（本リポジトリにテストスクリプトなし）
